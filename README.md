# MandaGram Shabbat Enforcer Plugin (C ABI) v1.0.0

Нативный плагин для клиента **MandaGram** ([mandagram.com](https://mandagram.com)) на языке **C**, обеспечивающий соблюдение Шаббата: плагин закрывает мессенджер в святое время и не позволяет отвлекаться на переписки.

Разработано в строгом соответствии со спецификацией **MandaGram C ABI SDK** (мост на базе Java Foreign Function & Memory API).

---

## 🕊️ Основные возможности

* **Защита при запуске**: если MandaGram открывается во время Шаббата, плагин сразу показывает предупреждающее окно и завершает работу приложения ещё до загрузки чатов.
* **Фоновый дозор**: если клиент уже был запущен до наступления Шаббата, легковесный фоновый поток каждые 15 секунд сверяет локальное время. Как только наступает время Шаббата, пользователю выводится уведомление, и процесс корректно закрывается.
* **Кроссплатформенность**:
  * **Windows**: нативное системное модальное окно `MessageBoxA` (`MB_SYSTEMMODAL` поверх всех окон) и чистый выход через `ExitProcess`.
  * **Linux**: поддержка GUI-диалога через `zenity` (при наличии в системе) и вывод в `stderr`, многопоточность на `pthread`.
* **Режим отладки**: возможность принудительной симуляции Шаббата в любое время через одну директиву препроцессора.

## ⏰ Расписание Шаббата по умолчанию

| День недели | Время наступления / окончания | Статус |
| :--- | :--- | :--- |
| **Пятница** | **18:00** | Начало Шаббата (вход заблокирован, клиент закрывается) |
| **Суббота** | Весь день до **21:30** | Шаббат продолжается (клиент закрывается) |
| **Суббота** | После **21:30** | Окончание Шаббата (доступ открыт) |
| **Воскресенье — Четверг** | Круглосуточно | Обычный режим работы |

Параметры времени можно легко настроить в начале файла [`src/shabbat_plugin.c`](src/shabbat_plugin.c):
```c
#define SHABBAT_START_WDAY 5   /* Пятница */
#define SHABBAT_START_HOUR 18  /* 18:00 */
#define SHABBAT_START_MIN  0

#define SHABBAT_END_WDAY   6   /* Суббота */
#define SHABBAT_END_HOUR   21  /* 21:30 */
#define SHABBAT_END_MIN    30
```

## 🧪 Тестирование (Debug Mode)

Чтобы протестировать поведение плагина прямо сейчас (в любой день недели и время):

1. Откройте [`src/shabbat_plugin.c`](src/shabbat_plugin.c).
2. Раскомментируйте строку:
   ```c
   #define FORCE_SHABBAT_DEBUG 1
   ```
3. Пересоберите плагин (`make`). При запуске MandaGram сразу среагирует и закроется с предупреждением: *«Шаббат Шалом! В Шаббат Telegram запрещен.»*.

## 🔨 Сборка

### Требования
* Компилятор `gcc` (для сборки под Linux).
* `mingw-w64` (`x86_64-w64-mingw32-gcc`, для кросс-компиляции под Windows).

### Команды

Собрать плагин под Linux (`out/shabbat_plugin.so`):
```bash
make linux
```

Собрать плагин под Windows (`out/shabbat_plugin.dll`):
```bash
make windows
```

Собрать под обе платформы:
```bash
make both
```

Очистить артефакты сборки:
```bash
make clean
```

## 📦 Установка в MandaGram

1. Соберите нужную версию плагина (`.so` для Linux или `.dll` для Windows).
2. Поместите скомпилированный файл в директорию плагинов MandaGram:
   * **Linux**: `~/.local/share/mandagram/plugins/` (или каталог `plugins/` рядом с исполняемым файлом MandaGram)
   * **Windows**: `%APPDATA%\MandaGram\plugins\` (или каталог `plugins/` рядом с `MandaGram.exe`)
3. Перезапустите MandaGram. В логах клиента появится сообщение об успешной инициализации:
   ```text
   [Shabbat] Плагин контроля Шаббата инициализирован.
   ```

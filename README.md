# MandaGram Shabbat Enforcer Plugin (C ABI) v2.0.0

Нативный плагин для клиента **MandaGram** ([mandagram.com](https://mandagram.com)) на языке **C**, обеспечивающий соблюдение Шаббата: плагин блокирует интерфейс мессенджера стильным оверлеем в святое время и предотвращает отправку любых сообщений без аварийного закрытия приложения.

Разработано в строгом соответствии со спецификацией **MandaGram C ABI SDK** (мост на базе Java Foreign Function & Memory API).

---

## 🕊️ Основные возможности

* **Интерфейсный оверлей (Overlay Mode)**: во время наступления Шаббата поверх окна MandaGram активируется стильный полноразмерный оверлей с сообщением *«🕯️ Шаббат Шалом! 🕯️»*, предотвращающий доступ к чатам и интерфейсу. Мессенджер остаётся запущенным, но надёжно заблокированным.
* **Перехват отправки сообщений (TDLib / FFI Hook)**: плагин регистрирует хук `register_message_send_hook`, который блокирует отправку исходящих сообщений в святое время на сетевом уровне.
* **Фоновый дозор**: легковесный фоновый поток сверяет системное локальное время и плавно отображает или скрывает оверлей при наступлении и завершении Шаббата.
* **Кроссплатформенность**:
  * **Windows**: нативный оверлей Win32 с поддержкой Unicode (UTF-8, эмодзи, шрифты Segoe UI через `DrawTextW`), корректным циклом обработки очереди сообщений (`MsgWaitForMultipleObjects`) и безопасным управлением дескрипторами GDI.
  * **Linux**: оверлей X11 с поддержкой масштабируемых UTF-8 шрифтов (`Xutf8DrawString`), позиционируемый непосредственно над окном MandaGram без блокировки остального рабочего стола операционной системы.
* **Режим отладки (Debug Mode)**: возможность принудительной симуляции Шаббата в любое время через одну директиву препроцессора.

## ⏰ Расписание Шаббата по умолчанию

| День недели | Время наступления / окончания | Статус |
| :--- | :--- | :--- |
| **Пятница** | **18:00** | Начало Шаббата (интерфейс блокируется, отправка сообщений запрещена) |
| **Суббота** | Весь день до **21:30** | Шаббат продолжается (клиент заблокирован) |
| **Суббота** | После **21:30** | Окончание Шаббата (доступ открыт) |
| **Воскресенье — Четверг** | Круглосуточно | Обычный режим работы |

Параметры времени можно легко настроить в начале файла [`src/shabbat_plugin.c`](src/shabbat_plugin.c):
```c
#define SHABBAT_START_WDAY 5   /* Пятница */
#define SHABBAT_START_HOUR 18  /* 18:00 */
#define SHABBAT_START_MIN  0

#define SHABBAT_END_WDAY   6   /* Суббота */
#define SHABBAT_END_HOUR   21  /* 21:30 */
#define SHABBAT_END_MIN    30
```

## 🧪 Тестирование (Debug Mode)

Чтобы протестировать поведение плагина прямо сейчас (в любой день недели и время):

1. Откройте [`src/shabbat_plugin.c`](src/shabbat_plugin.c).
2. Раскомментируйте строку:
   ```c
   #define FORCE_SHABBAT_DEBUG 1
   ```
3. Пересоберите плагин (`make`). При запуске MandaGram сразу среагирует и заблокирует интерфейс заглушкой: *«🕯️ Шаббат Шалом! 🕯️ Интерфейс заблокирован до 21:30 субботы.»*.

## 🔨 Сборка

### Требования
* Компилятор `gcc` (для сборки под Linux).
* `mingw-w64` (`x86_64-w64-mingw32-gcc`, для кросс-компиляции под Windows).

### Команды

Собрать плагин под Linux (`out/shabbat_plugin.so`):
```bash
make linux
```

Собрать плагин под Windows (`out/shabbat_plugin.dll`):
```bash
make windows
```

Собрать под обе платформы:
```bash
make both
```

Очистить артефакты сборки:
```bash
make clean
```

## 📦 Установка в MandaGram

1. Соберите нужную версию плагина (`.so` для Linux или `.dll` для Windows).
2. Поместите скомпилированный файл в директорию плагинов MandaGram:
   * **Linux**: `~/.local/share/mandagram/plugins/` (или каталог `plugins/` рядом с исполняемым файлом MandaGram)
   * **Windows**: `%APPDATA%\MandaGram\plugins\` (или каталог `plugins/` рядом с `MandaGram.exe`)
3. Перезапустите MandaGram. В логах клиента появится сообщение об успешной инициализации:
   ```text
   [Shabbat] Shabbat Enforcer v2.0 (Overlay Mode) успешно активирован.
   ```
